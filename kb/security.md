## Certifications
ISO 27001:2022 and ISO 27018:2025 certified; routine SOC 2 Type II audits. The SOC 2 report is available on request under NDA; ISO certificates are available without NDA.

## Hosting
Hosted on AWS. Primary region AWS Ireland, backup region AWS Germany, disaster recovery in AWS Frankfurt. Data residency outside the EU (for example US-only hosting) is not described on this page.

## Backups
Backed up at least daily and fully restorable. Customers are advised to also back up via scheduled reports or the API.

## Encryption
TLS 1.2+ in transit; AES-256 at rest; financial and salary data additionally encrypted at the application layer with KMS.

## Access
Native login and/or enterprise SSO; SSO with 2FA is recommended. Customer admins configure role-based access. HiBob staff access customer data only for audited support tasks with customer consent.

## Testing
Annual third-party penetration tests, OWASP scanning, static code analysis, and a Bugcrowd bug bounty program. No customer data in development or test environments.
